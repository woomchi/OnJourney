# 웹 환경 개선 사항
- 차량 경로 api 호출 실패

- 화면 크기가 급격히 변화하면(화면 회전 / 브라우저 크기 변경 등) 지도 줌이 제대로 되지 않음(심지어 영구 저장)
    - 마커와 polyline이 포함되도록 줌 정렬이 돼야하지만, 일부만 보이도록 설정됨(전체 여정 보기 버튼도 줌 정렬이 일부만 보이는 줌으로 같이 설정됨)
    - 모바일 크기로 전환하면 줌이 잘 정렬되지만 웹 환경으로 전환되면 이전에 이상한 줌 정렬로 설정됨(웹 줌 설정 관리 불일치 및 문제)

- 화면 크기 전환 시 화면 로딩 스피너를 통해 런타임 에러 방지
- url 라우팅을 통해 페이지 주소를 달리하여 브라우저의 뒤로가기, 앞으로가기 기능 구현
- 여정 상세 '목록 / 편집' 버튼 위치 조금 아래로 조정 필요
- 여정 상세 편집 상태에서의 '취소 / 완료'도 마찬가지로 위치 조금 아래로 조정 필요

- 검색 플랫폼 노출을 위한 설정 파일 추가 필요(네이버/구글)

- 기차 / 고속버스
    - 상세 정보(시간대) 누락
    - 분 단위로만 시간 계산
    - 이전 장소 위치와 출발지, 탑승지가 500m 반경 안에 없다면 대안에서 제외
        - 이로 인해 아예 대안이 제공되지 않는 경우 발생 고려
