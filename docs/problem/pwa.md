- 장소 검색 바텀 시트 오버스크롤 미구현
- 오버스크롤 기능 중 최대 높이일 때는 한 번 더 스냅해야 오버 스크롤 작동하는게 아니라 바로 오버스크롤 되도록 수정이 필요
- 전체 여정 보기 버튼 클릭 후, 하이라이트 해제 안됨
- TMAP 도보 경로 호출 실패(?) : 직선 거리로 받아오는 중

- 여정 재생 시 다음 이동 경로로 전환되면 UI 전체가 30px 정도 위로 올라가서 렌더링

# 모바일 환경 개선
- 검색 기능에서 입력 중에는 추천 검색어만 띄움. 검색 실행 시(enter/다음/완료 클릭) 바텀 시트에 검색 결과 노출
- 검색 완료시 키보드 내려가기, 추천 검색어 리셋
- 검색 바텀 시트에서 닫기 버튼 플로팅버튼으로 변경 및 바텀 시트 최소 높이 스냅 포인트 삭제
- 검색 바텀 시트 기본 높이 30px 늘림

- 전체적으로 UI 글씨 크기 키워야함
- 다크 모드일 때 색상 구별이 잘 안가고 가독성이 떨어짐

- 경로 불러오는 동안에는 각 이동 정보 카드에 스켈레톤 효과 적용
