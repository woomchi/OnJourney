# 모바일 환경 개선
- 검색 완료시 키보드 내려가기, 추천 검색어 리셋
- 검색 바텀 시트 기본 높이 30px 늘림
- 전체적으로 UI 글씨 크기 키워야함(크롬 개발 도구 앱 화면으로 로컬 테스트했을 때는 문제가 없었는데 삼성 인터넷으로 테스트했을 때 UI 글씨가 다 너무 작아 보임. 이는 크롬 브라우저 기본 배율과 내 핸드폰 배율의 문제이긴하지만, 이런 경우는 사용자가 왜 이렇게 글씨가 작아?라는 의문을 가질 수도 있을 것 같음. 따로 설정에서 배율 관련 기능을 추가해야하는지 고려 필요. 혹은 rem 단위를 사용해서 폰트 크기를 키우는 것을 고려해야할 수도 있음)

- 다크 모드일 때 색상 구별이 잘 안가고 가독성이 떨어짐

- 경로 불러오는 동안에는 각 이동 정보 카드에 스켈레톤 효과 적용
