1. 영구 저장 및 자체 DB(데이터베이스) 구축 금지
핵심 내용: API를 호출하여 반환받은 결과값(정류장 정보, 노선 정보, 경로 탐색 결과 등)을 서버에 영구적으로 저장하여 자체적인 대중교통 데이터베이스를 구축하는 것은 엄격히 금지됩니다.

이유: 대중교통 데이터의 저작권을 보호하고, 무단 복제 및 스크래핑(Scraping)을 방지하기 위함입니다.

2. 임시 저장(캐싱, Caching)의 엄격한 제한
핵심 내용: 서비스의 응답 속도 향상이나 서버 부하를 줄이기 위한 목적의 임시 저장(캐싱)은 일부 허용될 수 있으나, 이 경우에도 최단 시간 내에 데이터를 파기해야 하며 장기 보관은 불가합니다.

이유: 대중교통 정보(노선 변경, 요금 인상, 시간표 변경 등)는 수시로 변동되므로, 사용자에게 잘못된 과거 정보가 노출되는 것을 막기 위함입니다. 항상 실시간 API 호출을 통해 최신 데이터를 제공하는 것을 원칙으로 합니다.

3. 데이터의 2차 가공 및 제3자 제공(재배포) 금지
핵심 내용: API를 통해 수집한 데이터를 변형 및 가공하여 새로운 형태의 데이터를 만들거나, 이를 다른 기업이나 개인(제3자)에게 유상/무상으로 재배포, 판매, 공유하는 행위는 금지됩니다.

적용 범위: 앱/웹 서비스 내에서 최종 사용자에게 화면으로 보여주는 용도로만 사용해야 합니다.

4. 제휴 및 계약 종료 시 데이터 파기 의무
핵심 내용: ODsay API 이용 계약이 종료되거나 서비스 이용이 중단될 경우, 그동안 API를 통해 취득하여 내부 서버나 클라이언트에 남아있는 모든 관련 데이터를 즉시 영구 삭제해야 합니다.

5. 서비스 목적 외 사용 금지
핵심 내용: API 키(Key)를 발급받을 때 등록한 서비스(앱/웹) 이외의 다른 서비스나 플랫폼에서 해당 데이터를 공유하여 사용하는 것은 제한됩니다.
